# Mariscos Luse

Demostración de tienda de pescados y mariscos para Buenaventura.

## Publicación estática en Cloudflare Pages

Este repositorio incluye la aplicación estática en index.html, sin instalación de dependencias en el servidor. Elegir Framework: None; dejar el comando de compilación vacío; directorio de salida: / (raíz del repositorio).

El archivo mariscos-luse-fuente.zip conserva el código React original. Para desarrollarlo: extraer en otra carpeta, ejecutar npm ci, npm test y npm run dev. Para compilar: npm run build.

## Estado

Catálogo, filtros, favoritos, carrito, formulario, historial local y enlace a WhatsApp. Es una prueba: los pedidos se guardan solamente en el navegador. No hay base de datos compartida ni panel del personal. Precios, stock e imágenes son de referencia.

No usar para ventas reales. No incluye datos de clientes ni credenciales. El respaldo del código no sustituye un respaldo de base de datos. No hay respaldo automático recurrente activo.
