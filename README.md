# Mariscos Luse

Prototipo local de tienda de pescados y mariscos en Buenaventura.

## Recuperar el proyecto

Descarga `mariscos-luse-fuente.zip` y extrae su contenido en una carpeta. Con Node.js instalado, ejecuta:

```
npm ci
npm test
npm run dev
```

Para compilar: `npm run build`.

## Estado

Catálogo, filtros, favoritos, carrito, formulario, historial local y enlace a WhatsApp. Es una demostración: los pedidos se guardan solo en el navegador; no hay base de datos compartida ni panel de personal. Precios, stock e imágenes de referencia. No utilizar para ventas reales todavía.

Esta copia conserva el código fuente y el archivo de versiones de dependencias. No incluye dependencias instaladas, credenciales ni datos de clientes. No constituye un respaldo de base de datos ni un respaldo automático recurrente.
